# Mehrafarin Kolahdoozan — Portfolio Website

Bilingual (Persian / English) psychotherapist portfolio site.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS

## Development

```bash
npm install
npm run dev
```

Open:

- http://localhost:3000/fa
- http://localhost:3000/en

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm run start` — serve production build
- `npm run lint` — ESLint

## Content

Localized copy lives in `content/fa` and `content/en`.
Verified profile facts and null placeholders live in `content/profile.ts`.

Do not invent contact details, fees, or credentials.
